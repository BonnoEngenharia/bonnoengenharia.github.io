# BONNO Engenharia e Arquitetura

Site institucional estático com portfólio, calculadora de estimativa estrutural e atendimento pelo WhatsApp.

## Publicação

GitHub Pages: branch `main`, diretório `/`.

## Manutenção

- `index.html`: conteúdo e aparência.
- `app.js`: cálculo, galerias e carrossel.
- `assets/`: imagens utilizadas no site.

Apenas estrutura em concreto armado convencional gera estimativa. Os demais serviços são sob consulta. A proposta final depende da análise da documentação. Dados do formulário são enviados ao WhatsApp pela ação do visitante; não há armazenamento em servidor ou pagamento pelo site.
