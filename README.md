# BONNO Engenharia e Arquitetura

Site institucional estático com portfólio, estimativa estrutural e solicitação de orçamento pelo WhatsApp.

## Publicação

GitHub Pages: branch `main`, diretório `/`.

## Manutenção

- `index.html`: conteúdo e aparência.
- `app.js`: formulário, galerias e carrossel.
- `assets/`: imagens utilizadas no site.

A estimativa automática vale apenas para estrutura em concreto armado convencional, com até 1.000 m² de área total construída e até 10 pavimentos. Os demais pedidos são sob consulta. A proposta final depende da análise da documentação. Dados do formulário são enviados ao WhatsApp pela ação do visitante; não há armazenamento em servidor ou pagamento pelo site.
