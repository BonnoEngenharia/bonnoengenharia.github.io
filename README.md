# BONNO Engenharia e Arquitetura

Site institucional estático com portfólio, formulário de orçamento sob consulta pelo WhatsApp.

## Publicação

GitHub Pages: branch `main`, diretório `/`.

## Manutenção

- `index.html`: conteúdo e aparência.
- `app.js`: formulário, galerias e carrossel.
- `assets/`: imagens utilizadas no site.

Todos os serviços são orçados sob consulta. A proposta final depende da análise da documentação. Dados do formulário são enviados ao WhatsApp pela ação do visitante; não há armazenamento em servidor ou pagamento pelo site.
